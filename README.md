# Artifact

Artifact for reproducing the CNN memory evaluation results, self-contained C code of TinyStories_v2 LLM model, and the full firmware for S32K3X4EVB-T172 evaluation
board in the paper  "te-comp: A Complete MLIR Compiler Generating Self-Contained C Inference Engines for MCUs"

##  Memory and Accuracy Benchmarks

- Please go to the folder `./benchmarks` and follow the steps in `./benchmarks/README.md`

## TinyStories_v2 Code Generation and Firmware

- Please go to the folder `./tinystories_v2_firmware` and follow the steps in `./tinystories_v2_firmware/README.md`
